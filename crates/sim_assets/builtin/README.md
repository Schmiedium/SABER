# Built-in 3D models

One folder per model: `<domain>/<slug>/{model.glb, model.ron}` (subsystems-and-interfaces.md §5.10,
D17). Every model is in the body frame (x forward, y right, z down, metres) with its origin at the
body's reference point, and is dedicated to the public domain (see `LICENSES.md`).

- The models are generated by `crates/sim_assets/examples/make_builtins.rs`. Change a model there,
  bump its `version` when its shape or frame changes, and run
  `cargo run -p sim_assets --example make_builtins` to rewrite the folders.
- `build.rs` lists the folders and embeds every `model.ron` (and the primitives' `model.glb`) in the
  binary, so there is no `catalog.ron` to keep in step.
- `cargo test -p sim_assets` checks every built-in against the library's rules.
- `thumb.png` files arrive with the Library's 3D Models tab (build step S5-2).
